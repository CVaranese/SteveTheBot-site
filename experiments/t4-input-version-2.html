Input version 2 (the zero line)

12 Nov 2026 · T-4 · Inputs

Abstract

No cost: input 2 wins 54 to 69 of 100 against input 1 runs.

No cost: input 2 runs as fast and wins 54 to 69 of 100 against input 1 runs (part of the same-batch margin is seed luck).

Question and hypothesis

To learn from recorded human games, the network must be given the same inputs from a replay as from the simulator. Some of the inputs used so far cannot be read from the replay dataset (for example the game's own animation frame counter, or hitstun). A second version of the inputs was therefore defined, built only from fields that both sources record. Before using it, this experiment asks whether it costs anything for ordinary training by self-play.

Written in the experiment plan on 12 Nov 2026, before the runs:

On every frame where a replay is still exactly together in the simulator, v2 built from the simulator equals v2 built from the replay arrays, all 796 numbers (tolerance 1e-4).

Building v2 in simbatch costs under 10% of rollout speed (guess).

"v2" is input version 2 and "simbatch" the code that builds the inputs during training. The first quote is the check that both sources give the same numbers; the second is about training speed. No expectation about games won was written down before these runs.

Discussion

Input version 2 cost no training speed. Table 2 gives the decisions per second of each run; the input 2 runs and the input 1 runs of this batch are at the same level, inside the second quote's bound.

Head to head, input version 2 was at least level. The input 2 runs won 68% of their games against the input 1 runs of the same batch and 54% against the two earlier input 1 runs. The difference between those two numbers shows how much the result depends on which input 1 runs are the opponents.

Against the scripted bot every model of the batch won few or no games. All of them act with a reaction delay against an opponent without one; Table 3's stocks columns are the more useful comparison there.

Limitations

  • Four runs against two (and two earlier ones). Runs of the same settings differ by a wide margin ("Each run").
  • The earlier input 1 runs were trained in another batch on the same day.
  • The check named in the first quote (both sources giving the same input) was run during the work and its output is not shown on this page.
  • Head-to-head games compare the models of these batches only with each other.
  • The scores were measured on the copy saved at the end of each run.
