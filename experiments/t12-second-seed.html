Second seed for the input variants

11 Nov 2026 · T-12 · Inputs

Abstract

The previous-action gain did not repeat; one run per variant cannot rank close variants.

The previous-action gain did not repeat (54 against 47); the small-start embedding looked best. Same-setting runs differ by 12 to 13 wins, so one run per variant cannot rank close variants.

Question and hypothesis

An earlier experiment tried two changes to the network's input with one training run each. Telling the network its own previous action scored well, and replacing the animation one-hot by a learned embedding scored badly. This experiment asks whether the first result holds with a second random seed, and whether the second was caused by the starting values of the embedding table.

Written in the experiment plan on 11 Nov 2026, before the runs:

T12Base vs frozen: 45 to 65 (two earlier seeds 54, 55).

T12Prev vs frozen: at least 10 more than T12Base. If not, the T-9 gain was mostly chance.

T12EmbSmall vs frozen: within 10 of the baselines (about 45 to 65) if the starting values were the cause; still near 32 if not.

T12EmbSmallPrev: within 10 of the previous-action runs.

In these quotes "T12Base" is the plain-input run of this experiment, "T12Prev" the run with the previous action, "T12EmbSmall" the run with an embedding whose table starts with small values, "frozen" a saved copy of the earlier model PPO8Self used as a fixed opponent, and "T-9" the earlier experiment. Numbers are wins out of 100 games.

Setup

Four new self-play runs: plain inputs and the previous action with a new seed, and the embedding with a small starting spread, with and without the previous action. The earlier experiment's four runs are listed beside them: its plain and previous-action runs as the other seed of the same setting, its two embedding runs (large starting spread) as a reference.

Discussion

The gain of the previous action did not repeat. Against the frozen model the "Each run" column of Table 3 shows the two plain-input runs and the two previous-action runs. In the earlier seed the previous action was far ahead; in the new seed the gap is small, below the margin the second quote set.

Runs of the same setting differ by about as much as the settings do. The two previous-action runs differ from each other by more than the new previous-action run differs from the new plain run (Table 3, "Each run").

The embedding with a small start scored far above the embedding with a large start. Against the frozen model the small start won 65% and the large start 32%; at level 9, 81% against 42%. This is the outcome the third quote tied to the starting values being the cause. It rests on one run of each.

With the previous action added, the starting spread made little difference. The two embedding runs with the previous action won 69% (small start) and 69% (large start) against the frozen model.

Limitations

  • One new run per setting; two runs in all for plain inputs and for the previous action, one for each embedding setting.
  • The two seeds of a setting come from two batches run at different times of the same day.
  • The small-start embedding's lead over plain inputs is one run and was not repeated here.
  • The opponents are this project's own; no model was scored against the game's own computer player.
  • The scores were measured on the copy saved at the end of each run.
