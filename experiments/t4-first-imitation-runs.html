First imitation runs

12 Nov 2026 · T-4 · Replays

Abstract

Every model so far had learned by playing against itself or a bot. Recorded human games are another source, and this experiment trains the bot's network to predict what a human pressed, asking whether a network that only copies humans can play a game on its own. Two networks were trained on the first 300 games of a dataset of human games with this character on both sides on this stage: one with plain cross-entropy, and one in which the frames where the human changes input count five times. Each then played the scripted bot at level 9. The plain network learned to repeat its last input: its accuracy on unseen games equals that of always repeating the last input, and it is right on only a few percent of the frames where the human changes input. Weighting those frames made the network predict them several times better, at a cost in overall accuracy. Neither network could play: each lost every game it played against the scripted bot and took almost no stocks, losing mostly by falling off the stage without using the recovery move. The network reaches positions that humans rarely show, so copying alone is not enough, and play from this start needs further training.

Question and hypothesis

Every model so far learned by playing against itself or a bot. Human play is another source: a dataset of recorded human games of the same character on the same stage. This experiment trains the bot's network to predict what the human pressed, and asks whether a network that only copies humans can play a game on its own.

Written in the experiment plan on 12 Nov 2026, before the runs:

Expected (guesses, written before the run): held-out accuracy 0.87 to 0.89 against 0.854 for "repeat the last queued input"; accuracy on frames where the human changes input 0.25 to 0.35; held-out loss still falling at the end (a 2x128 network without memory underfits).

level 9 scripted bot 10 to 60 wins.

Expected (written before): accuracy on changes 0.15 to 0.25, overall 0.80 to 0.83, at most 10 of 40 deaths self-destructs, some up-B offstage.

"Held-out" games are games the network never trained on. "Repeat the last queued input" is the trivial prediction that the human keeps pressing what they pressed last; humans change input on a small share of frames, so it is right most of the time. A "self-destruct" is a lost stock with no damage taken shortly before. "Up-B" is the special move the character uses to get back to the stage.

Discussion

The plain network learned to repeat its last input. Its held-out accuracy at the end is within a fraction of a point of the "repeat" baseline, and its accuracy on frames where the human changes input is a few percent (the first "update 6000" line). The first quote expected both clearly higher.

Weighting the changes made the network predict them, at a cost in overall accuracy. In the second "update 6000" line the accuracy on changes is several times higher and the overall accuracy is lower than the baseline. The accuracy on changes is inside the range of the third quote; the overall accuracy is below it.

Neither network can play. Both lost every scored game against the scripted bot (0 of 50 games and 0 of 50 games), against the second quote's expectation; the stocks columns of Table 2 show how little either took.

Limitations

  • The game count in the log line "games: 300 training" is taken before games with missing values are skipped; the line above it gives the number skipped.
  • The abstract's account of how the models lose (falling off the stage without using the recovery move) comes from an analysis whose output was not saved to a file, so it is not shown on this page.
  • One run of each kind, trained on a part of the dataset, with a short training length.
  • A model saved by this trainer acts every frame with an 11-frame reaction delay, so it plays the scripted bot at a disadvantage that the earlier models without delay did not have.
  • The dataset is another project's collection of human games; it is used privately and is not redistributed.

Decision

The user chose the next step: imitation on all games, then PPO from that start (above).
