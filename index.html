Model names

What the names on these pages mean. The models in the rankings are explained on the rankings page.

Parts of a name

  • T<number> at the startThe task that trained it (T21 is task T-21). Older models have no task number.
  • s<digit> or a last digitThe random seed: the same settings trained again from a different random start. Two seeds of one setting can differ a lot, so one run says little on its own.
  • Self / BotTrained by playing against itself, or against the level 3 scripted bot.
  • No checkpoint suffixTraining saves copies part-way (files named _c01, _c02, ...). Every model on this site is the copy saved at the end of its run, so the suffix is left out.

The models on this site

  • PPO8BotAs PPO8Self, but trained against the level 3 scripted bot.
  • PPO8Bot_editPPO8Bot with its weights edited by hand, no training: its choices made sharper (less random).
  • PPO8Bot_edit_recPPO8Bot with its weights edited by hand, no training: choices made sharper, plus a hand-wired recovery circuit.
  • PPO8SelfPPO with the repaired network of task T-8; trained against itself for 20 minutes.
  • PPOBotAs PPOSelf, but trained against the level 3 scripted bot.
  • PPOSelfPPO, the first new training method, still with the 2017 network; trained against itself for 20 minutes.
  • SimBaseThe 2017 learner (actor-critic), moved unchanged into the simulator and trained against itself for 48,000 updates (28 minutes). The starting point everything else is compared with.
  • SimBaseBotAs SimBase, but trained against the level 3 scripted bot.
  • Steve_2026-11-11_u21850The 2017 learner trained in Dolphin against the level 3 in-game CPU, a copy saved part-way, at 21,850 updates (about 3.5 hours).
  • T12BaseTask T-12: T9Base trained again with a third random seed.
  • T12EmbSmallTask T-12: the animation embedding started small, which T9Emb was not.
  • T12EmbSmallPrevTask T-12: the small-start embedding plus the previous button press.
  • T12PrevTask T-12: T9Prev trained again with a third random seed.
  • T16Base3Task T-16 (controls): the usual controls (a decision every 2 frames, no reaction delay), random seed 3.
  • T16F1D15s3Task T-16: a decision every frame, with a human-like 15-frame reaction delay, random seed 3.
  • T16F1s3Task T-16: a decision every frame, no reaction delay, random seed 3.
  • T17F102s3Task T-17: as T17F54, but 102 inputs (more stick positions) in one list, random seed 3.
  • T17F54s3Task T-17 (controller): a decision every frame with an 11-frame reaction delay, the usual 54 inputs in one list, random seed 3.
  • T17H102s3Task T-17: as T17F102, but chosen in two steps (button, then stick), random seed 3.
  • T19Base3Task T-19 (faster experiments): trained on the graphics card at full length (2,940 updates), with the usual inputs, random seed 3.
  • T19Emb2Task T-19 (faster experiments): trained on the graphics card at full length (2,940 updates), with the animation embedding, random seed 2.
  • T19EmbSmall2Task T-19 (faster experiments): trained on the graphics card at full length (2,940 updates), with the animation embedding, started small, random seed 2.
  • T19hBase3Task T-19 (faster experiments): a run planned for half the length (1,470 updates), with the usual inputs, random seed 3.
  • T19L12Base3Task T-19 (faster experiments): a half-length run at four times the learning rate, with the usual inputs, random seed 3.
  • T19L6Base3Task T-19 (faster experiments): a half-length run at twice the learning rate, with the usual inputs, random seed 3.
  • T19Prev3Task T-19 (faster experiments): trained on the graphics card at full length (2,940 updates), with the previous button press as an input, random seed 3.
  • T21L3Cs3Task T-21: the usual learning rate (0.0003) held constant instead of lowered, random seed 3.
  • T21L6Cs3As T21L6Cs4 (twice the learning rate, held constant), random seed 3.
  • T21L6Cs4Task T-21: self-play at twice the usual learning rate (L6: 0.0006), held constant for the whole run (C), random seed 4. The strongest model of its batch, and the opponent in the scenario tests and in one of the rankings.
  • T21L6s3Task T-21: self-play at twice the usual learning rate (0.0006), lowered to zero over the run as usual, random seed 3.
  • T22Base5Task T-22: the T21L6Cs4 settings again (usual inputs), random seed 5.
  • T22Base6Task T-22: the T21L6Cs4 settings again (usual inputs), random seed 6.
  • T22EmbSmall3Task T-22: the T21L6Cs4 settings plus the small-start animation embedding, random seed 3.
  • T22L12Cs3Task T-22: four times the usual learning rate (0.0012), held constant, random seed 3.
  • T22LongBase7Task T-22: the T21L6Cs4 settings trained twice as long (5,880 updates), random seed 7.
  • T22LongBase8Task T-22: the T21L6Cs4 settings trained twice as long (5,880 updates), random seed 8.
  • T22LongEmb9Task T-22: the small-start embedding trained twice as long (5,880 updates), random seed 9.
  • T22Scale3Task T-22: the T21L6Cs4 settings with positions and hitstun rescaled to a similar size, random seed 3.
  • T37H4s8_7Task T-37: as T37Plain, but the input also holds the game state from the last 4 states, 8 frames apart (frame history), random seed 7.
  • T37H4s8_7 (double length)Task T-37: as T37Plain, but the input also holds the game state from the last 4 states, 8 frames apart (frame history), random seed 7. Trained twice as long: 5,880 updates instead of 2,940.
  • T37H8s4_7Task T-37: as T37Plain, but the input also holds the game state from the last 8 states, 4 frames apart (frame history), random seed 7.
  • T37H8s4_7 (double length)Task T-37: as T37Plain, but the input also holds the game state from the last 8 states, 4 frames apart (frame history), random seed 7. Trained twice as long: 5,880 updates instead of 2,940.
  • T37Plain7Task T-37 (memory of past frames), the comparison runs: as T4V2, no frame history, random seed 7.
  • T37Plain7 (double length)Task T-37 (memory of past frames), the comparison runs: as T4V2, no frame history, random seed 7. Trained twice as long: 5,880 updates instead of 2,940.
  • T40M128s7Task T-40 (matches per run): as T4V2, but 128 matches played at once in one run (64 is the usual), the same total game time, random seed 7.
  • T40M256s7Task T-40 (matches per run): as T4V2, but 256 matches played at once in one run (64 is the usual), the same total game time, random seed 7.
  • T40M64s7Task T-40 (matches per run): as T4V2, but 64 matches played at once in one run (64 is the usual), the same total game time, random seed 7.
  • T4HumH1As T4HumP, but started from T4ImFullH4, the imitation network with frame history; random seed 1.
  • T4HumKa1As T4HumP, plus a penalty for drifting away from the imitation policy (KL coefficient 0.1), random seed 1.
  • T4HumKb1As T4HumP, plus a penalty for drifting away from the imitation policy (KL coefficient 1.0), random seed 1.
  • T4HumP1Task T-4, the human line: PPO self-play (2,940 updates, current controls, input version 2) started from T4ImFull, the network that copied human replays, instead of from scratch; random seed 1.
  • T4HumP2Task T-4, the human line: PPO self-play (2,940 updates, current controls, input version 2) started from T4ImFull, the network that copied human replays, instead of from scratch; random seed 2.
  • T4Im300Task T-4: a network that only copies human play (imitation), trained on 254 Falcon ditto replays; the copy saved after 2 of its checkpoints, the one played. No PPO.
  • T4Im300W5As T4Im300, with frames where the human changes input counting 5 times in the training; the first checkpoint. No PPO.
  • T4ImFullTask T-4: imitation of all 1,236 usable Falcon ditto replays on Final Destination, 20,000 updates. No PPO; the start of T4HumP.
  • T4ImFullH4As T4ImFull, with frame history (4 states, 8 frames apart). The start of T4HumH.
  • T4V1s5Task T-4 (learning from replays), the comparison runs: self-play, a decision every frame with an 11-frame reaction delay, the usual inputs (version 1), random seed 5.
  • T4V2s3Task T-4: as T4V1, but with input version 2, built only from what both the simulator and human replays record, random seed 3.
  • T4V2s4Task T-4: as T4V1, but with input version 2, built only from what both the simulator and human replays record, random seed 4.
  • T9BaseTask T-9 input experiment: PPO8Self trained again (another random start), the usual inputs.
  • T9EmbAs T9Base, plus an animation embedding: each animation turned into 32 learned numbers.
  • T9EmbPrevAs T9Base, with both the animation embedding and the previous button press.
  • T9PrevAs T9Base, plus the bot's own previous button press as an input.
  • scripted bot level 9Not a network: a hand-written Falcon that recovers and attacks. Level 9 is its hardest setting.
