How to read a model name
T at the start
The task that trained it (T21 is task T-21). Older models have no task number.
s or a last digit
The random seed: the same settings trained again from a different random start. Two seeds of one setting can differ a lot, so one run says little on its own.
Self / Bot
Trained by playing against itself, or against the level 3 scripted bot.
No checkpoint suffix
Training saves copies part-way (files named _c01, _c02, ...). Every model on this site is the copy saved at the end of its run, so the suffix is left out.
