# SteveTheBot site

Viewable pages for [SteveTheBot](https://github.com/CVaranese/SteveTheBot), served by GitHub Pages at
https://cvaranese.github.io/SteveTheBot-site/ .

- `roadmap.html`: the roadmap and progress page.
- `scenarios/`: scenario playback pages (sample starts per model).
- `reports/`: game report timelines.

To update: `python build.py` (copies the current pages from a SteveTheBot checkout beside this folder and rebuilds
`index.html`), then commit and push.
